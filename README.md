## ✨ المميزات الرئيسية للإصدار 3.0.0 (Features)

- **🎮 تحديد نوع النشاط في ديسكورد (Activity Type Selector):**
  - دعم كامل لجميع أنواع أنشطة ديسكورد الرسمية:
    - **يلعب (Playing)**
    - **يبث مباشر (Streaming)** باللون البنفسجي مع رابط Twitch أو YouTube Live.
    - **يستمع إلى (Listening to)**
    - **يشاهد (Watching)**
    - **يتنافس في (Competing in)**

- **⏱ توقيت مخصص لكل فريم وأنماط تنقل ذكية (Custom Frame Duration & Modes):**
  - تخصيص مدة بقاء مستقلة لكل فريم بالثواني (مثلاً فريم 10ث، فريم 3ث).
  - 3 أنماط تنقل: **متسلسل (Sequential)**، **عشوائي (Random)**، و**ذهاب وإياب (Ping-Pong)**.

- **▶ محاكاة متحركة حية داخل التطبيق (Live Rotator Simulation):**
  - شريط تحكم كامل في شاشة المعاينة (تشغيل/إيقاف، تنقل سريع، مؤشر الفريم الحالي، وشريط تقدم زمني ناعم) لمشاهدة التنقل الحي قبل تشغيله في ديسكورد.

- **🎵 الـ RPC الموسيقي الحي (Live Media & Song Presence):**
  - تعرّف ذكي وتلقائي على الأغاني المشغلة على ويندوز (تطبيق Spotify المكتبي، YouTube في المتصفحات، مشغلات الصوت) وإظهارها فورياً بنوع `Listening to`.

- **📡 استوديو إرسال الويب هوك وتصميم Embeds (Webhook Studio):**
  - تبويب كامل ومخصص لتصميم Embeds احترافية مع معاينة حية مطابقة لديسكورد.
  - دعم العناوين، الأوصاف (Markdown)، كاتب الرسالة، البانرات، الصور المصغرة، الحقول المخصصة (Fields & Inline)، الفوتر، والتوقيت.
  - قوالب جاهزة سريعة (إعلان سيرفر رسمي، قوانين السيرفر، تحديث جديد، رسالة ترحيب) وإرسال فوري إلى سيرفرك بنقرة زر.

- **⚡ تحسين استهلاك الرام والعمل في الخلفية (RAM & Tray Optimization):**
  - استهلاك خفيف ومحسن للذاكرة، مع تصغير تلقائي لشريط المهام (System Tray) عند إغلاق النافذة.

- **👤 مزامنة الملف الشخصي والشارات من ديسكورد:**
  - سحب الاسم المعروض واسم المستخدم، الأفاتار الأصلي عالي الدقة، إطار الأفاتار التفاعلي (Avatar Decoration)، وشارات ديسكورد الرسمية (Nitro, HypeSquad, Active Developer, Partner, Mod).

- **💾 نظام الحفظ التلقائي اللحظي (Live Auto-Save):**
  - حفظ فوري ومستمر لجميع الإعدادات والروابط والبروفايلات والفريمات دون الحاجة للنقر على أي زر يدوي.

## 📥 التحميل المباشر (Direct Download)

يمكنك تحميل النسخة الجاهزة للتشغيل مباشرة على نظام ويندوز (بدون الحاجة لتثبيت أي برامج إضافية):

👉 **[اضغط هنا لتحميل أحدث إصدار من صفحة Releases](https://github.com/sloom555555/naml-rpc/releases/latest)**

1. حمّل ملف `Naml-v2.0.0-Windows-x64.zip`.
2. فك الضغط عن الملف في أي مكان تريده.
3. شغّل ملف `Naml.exe` مباشرة واستمتع بالتطبيق!

## 💻 التشغيل من المصدر للمطورين (Run from Source)

إذا كنت تفضل تشغيل المشروع من سطر الأوامر والتطوير عليه:

```bash
# 1. استنساخ المستودع
git clone https://github.com/sloom555555/naml-rpc.git
cd naml-rpc

# 2. تثبيت الحزم والمكتبات
npm install

# 3. تشغيل التطبيق
npm start
```
