## ✨ المميزات الرئيسية (Features)

- **👤 مزامنة الملف الشخصي من ديسكورد:**
  - سحب الاسم المعروض (Display Name) واسم المستخدم (`@username`).
  - سحب الأفاتار الأصلي عالي الدقة (صور ثابتة ومتحركة GIF).
  - **إطار الأفاتار التفاعلي (Avatar Decoration):** عرض ديكور الأفاتار المخصص لحسابك كما يظهر في ديسكورد تماماً.

- **🏅 دعم كامل لشارات ديسكورد الرسمية (Discord Badges):**
  - دعم نيترو (Nitro)، هايب سكواد (HypeSquad Bravery, Brilliance, Balance)، المطور النشط (Active Developer)، الداعم المبكر (Early Supporter)، والمشرفين والشركاء بأيقونات SVG دقيقة.

- **💾 نظام الحفظ التلقائي اللحظي (Live Auto-Save):**
  - حفظ فوري ومستمر لجميع النصوص والروابط والصور والبروفايلات والفريمات دون الحاجة للنقر على أي زر يدوي، مع مؤشر حفظ تفاعلي.

- **🔄 الـ RPC المتحرك والمشاهد المتغيرة (Dynamic Rotator Engine):**
  - التنقل التلقائي بين مشاهد وفريمات متعددة ومخصصة (بث تويتش، FiveM، الروم الصوتي، Spotify، إلخ).
  - **Live Hardware Monitor:** مراقبة واستهلاك المعالج (CPU) والرام (RAM) حياً في حالة الديسكورد.

- **🤖 إدارة توكنات البوتات:**
  - تخصيص اسم وصورة وبانر وبايو البوتات، وتطبيق حالات تفاعلية (Playing, Streaming, Listening, Watching, Competing).

- **🔧 أدوات الأمان والإصلاح الذاتي:**
  - فحص تلقائي لمقبس ديسكورد، منع تعارض العمليات (Single Instance Lock)، مسح الكاش بنقرة زر، ونسخ احتياطي شامل.
